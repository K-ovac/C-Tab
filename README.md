# 🚀 Crypto Tracker App (iOS)

Современное и функциональное iOS-приложение на SwiftUI для отслеживания криптовалютного рынка, просмотра детальной статистики по токенам и управления персональными настройками.

## ✨ Основные Возможности

### 📊 1. Главный экран (`HomeView`)
* **Глобальные метрики рынка:**
  * Общая капитализация рынка (с изменением за 24 часа в %);
  * Суммарный объем торгов за 24 часа;
  * Индекс доминирования ведущей криптовалюты (#1 Coin).
* **Трендовые монеты (Trending Coins):** Сетка `LazyVGrid` из 4 трендовых активов.
* **Топ монет:** Список Top-10 монет с кнопкой перехода к полному списку.
* **Быстрая навигация:** Кнопки перехода к модальному окну профиля/настроек и экрану поиска.

### 🔍 2. Поиск и Фильтрация (`TopCoinsListView`)
* Поиск токенов по названию или тикеру (`TextField`).
* **Фильтрация по количеству:** Отображение Top-20, Top-100, Top-200 или всех доступных монет.
* **Выбор таймфрейма (Price Change):** Изменение цены за `1h`, `24h`, `7d`, `30d`, `1y`.
* **Гибкая сортировка:**
  * По рыночной капитализации (по возрастанию / убыванию);
  * По цене;
  * По изменению цены за 24 часа (в %).

### 📈 3. Детальный экран Коина (`CoinDetailsView`)
* **Кастомный Navigation Bar:** Кнопка возврата с индикацией списка и символом валютной пары (например, `BTC/USD`).
* **Дисклеймер:** Предупреждение о том, что данные предоставлены третьей стороной (CoinGecko API) и не являются инвестиционной рекомендацией.
* **Карточка актива:** Логотип, символ, название, текущий рейтинг, последняя цена и динамика за 24 часа.
* **Подробная статистика:**
  * High / Low цена за 24 часа;
  * Рыночная капитализация (Market Cap);
  * Циркулирующее предложение (Circulating Supply);
  * Полностью размытая оценка (FDV);
  * Общее и максимальное предложение (Total & Max Supply);
  * Суммарный объем торгов (Trading Volume).
* **Описание монеты:** Сворачиваемый блок текста (3 строки по умолчанию) с кнопкой «Показать больше».
* **Внешние ссылки:** Переход на официальные веб-ресурсы монеты.

### ⚙️ 4. Профиль и Настройки (Modal Sheet)
* **Учетные данные:** Краткая карточка пользователя.
* **Конфигурация приложения** (переходы через `NavigationStack` / `navigationDestination`):
  * Выбор отображаемой валюты;
  * Смена темы оформления (Dark / Light );
  * Выбор языка приложения.
  *(Все пользовательские предпочтения локально сохраняются в **`UserDefaults`**)*.
* **Дополнительные сервисы:**
  * Политика конфиденциальности (открывается в `SafariView`);
  * Оценка приложения (прямой редирект в App Store).
* **Версия приложения** и кастомная кнопка закрытия (`xmark`) в трейлинг-баре.

## 🛠 Технологический Стек и Архитектура

* **Платформа:** iOS 18.0+
* **Фреймворк:** SwiftUI
* **Архитектурный паттерн:** MVVM (Model-View-ViewModel) с четким разделением ответственности.
* **Сетевой слой:** `URLSession`, `URLRequest`, кастомный менеджер сетевых запросов.
* **Асинхронность:** Modern Concurrency (`async` / `await`, `Tasks`).
* **Хранение данных:** `UserDefaults` (для сохранения выбранной валюты, темы и языка).
* **UI Компоненты:** `LazyVGrid`, `NavigationStack`, `Sheet`, `SafariView`, Custom Toolbar, List, SFSafariViewController, Link, LazyVStack, HStack, VStack.

---

## ⚠️ Обработка Ошибок и Состояний Загрузки

* **Обработка сетевых ошибок:** Для всех ключевых секций главного экрана реализована обработка ошибок. В случае неудачной загрузки данных пользователь видит кастомное View с сообщением об ошибке и кнопкой **«Повторить» (Retry)**.
* **Состояние загрузки:** Во время выполнения асинхронных запросов отображается системный индикатор `ProgressView`.

## 🛠 Инструкция по Сборке и Запуску

### Требования
* Xcode 16.0+
* Swift 6.0+
* iOS 18.0+ (Симулятор или физическое устройство)

### Настройка Конфигурации и API-Ключа

Конфигурация сетевых запросов и ссылки содержатся в отдельном файле констант (например, `LinkConstants.swift`).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/K-ovac/C-Tab.git
   cd C-Tab
   ```
2. Откройте проект в Xcode (`.xcodeproj`).
3. Отредактируйте файл `LinkConstants.swift` по маршруту `~/C-Tab/C-Tab/Foundation/Requests/LinkConstants.swift`, указав необходимые данные:

```swift
import Foundation

enum RequestConstants {
    /// Основной URL для запросов к API
    static let baseURL = "https://pro-api.coingecko.com/api/v3/"
    
    /// API Ключ CoinGecko
    static let apiKey = "YOUR_API_KEY_HERE"
    
    /// Заголовки для HTTP-запросов
    static let apiHeader = "X-CMC_PRO_API_KEY"
}
```

4. Выберите нужный таргет и запустите проект (`Cmd + R`).
